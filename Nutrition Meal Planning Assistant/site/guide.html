接入说明

本页面说明营养配餐助手如何基于麦当劳中国官方 MCP Server 构建。 所有餐品、价格、门店、营养数据均来自官方接口，本站不存储任何硬编码营养值。

配餐调用流程

7 步 · 全部为官方工具

01 · 申请 MCP Token

登录开放平台

访问 open.mcd.cn，点击右上角「登录」，使用手机号验证码登录。

进入控制台

登录成功后，右上角「登录」变为「控制台」。

激活并复制 Token

点击「激活」申请 MCP Token，同意服务协议后即可一键复制。

02 · 接入配置

服务器接入地址 https://mcp.mcd.cn，使用 Streamable HTTP 协议，请求头携带 Bearer Token。

{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}

03 · 数据口径与工程约束（评审要点）

数据来源

  • 站点营养值来自 list-nutrition-foods 快照，共 — 条。
  • 菜单与价格来自 query-meals，共 — 款在售餐品。
  • 门店来自 query-nearby-stores，共 — 家。
  • 套餐组成来自 query-meal-detail，共 — 款。

关键约束

  • 组合餐不做营养近似：营养表只收录单品，套餐类餐品不参与热量计算，避免低估。
  • 规格差异会标注：如「可乐 → 可乐中杯」，界面显示实际营养来源。
  • 金额单位：菜单为元，calculate-price 返回分，展示前统一换算。
  • 下单需 productCode（菜单字段名为 code，需改名，否则静默返回 0）。
